
# Exercícios de Programação Orientada a Objetos

Este repositório reúne exercícios que desenvolvi durante meus estudos de Programação Orientada a Objetos (POO) em Python.

Os programas foram criados para praticar conceitos como classes, objetos, atributos, métodos, herança e encapsulamento.

## Exercícios

- **carro.py:** simulação de um carro com funções para acelerar, frear, abastecer e controlar seu estado.
- **saldo.py:** exercício de conta bancária para praticar encapsulamento e operações com saldo.
- **veículo.py:** exemplo de herança utilizando classes de veículos, carros e motos.
- **cachorro.py:** simulação de um cachorro virtual com controle de energia, alimentação e comportamento.

## Tecnologias

- Python
- Programação Orientada a Objetos

## Objetivo

Registrar minha evolução nos estudos de programação e continuar aprimorando meus conhecimentos por meio de exercícios práticos.
